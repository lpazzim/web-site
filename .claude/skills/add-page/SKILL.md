---
name: add-page
description: Create a new page/route on the site with pre-rendering, both languages, SEO metadata, navigation and tests. Use when the user asks for a new page, section with its own URL, or route.
argument-hint: "<path> [purpose]"
---

Create the page `$ARGUMENTS` following `.claude/rules/routes.md`.

1. **Route module**: `src/routes/<name>.tsx` with `export default function <Name>()` wrapped in `<Layout>`, one `<h1>`,
   semantic sections, design tokens and `LocaleLink` for internal links.
2. **Route table**: add `page("/<path>", "routes/<name>.tsx", "<name>")` inside `localizedPages` in `src/routes.ts`.
3. **Pre-render + sitemap**: add the path to `appPaths()` in `src/lib/site-paths.ts` (dynamic segments: map over the
   data source, like `/work/:id`).
4. **Strings**: page copy and `seo.<name>.title/description` in both `src/i18n/locales/en.json` and `pt-BR.json`.
5. **Meta**: `export function meta({ location }: Route.MetaArgs)` returning `pageMeta(...)`; import
   `type { Route } from "./+types/<name>"` (generated by `pnpm typecheck`).
6. **Data**: static content from `src/content`; build-time data in a `loader` with server modules imported inside it;
   browser data with TanStack Query or a `clientLoader`.
7. **Navigation**: if the page belongs in the menu, add it to `NAV_ITEMS` in `src/components/Header.tsx` (and the footer
   if relevant) with a `nav.<key>` string.
8. **Tests**: a behavior test in `e2e/site.spec.ts`; `e2e/seo.spec.ts` covers metadata automatically through the sitemap.
9. Run `/verify` and preview the page in both languages, checking the console for hydration errors.
